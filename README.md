The village bakery is small business in the south of Johannesburg, that is more than just a bakery. It is a piece of the community, made with heart, heritage and a whole lot of flour. With more than 40 years of history, The Bakery opened its doors to the community in 1981 and has continued to serve generations of customers with freshly baked, quality products. They aim to grow the business beyond just being a local business but a nationally recognised brand.
Website Goals and Objectives:
Establish a searchable, credible online presence beyond word-of-mouth.
Give customers a single, accurate source for both branch addresses, trading hours and directions.
Showcase the product range with photography and descriptions.

project overview
The repository containts the front-end code for the village bakery website. The project aims to provide a good, responsive and user frinendly website for the bakery, allowing customers to view and order products, and contact the store.  
Updates:CSS styling 
In this phase, the website was enhanced with:
An external CSS stylesheet within a CSS folder linked to all HTML pages.
A base CSS reset and typography styles.
A responsive navigation bar using Flexbox.
CSS Grid layouts for product and team member sections.
A detailed footer with a grid layout.
Interactive elements using CSS pseudo-classes.
Media queries to ensure the website adapts seamlessly to mobile, tablet, and desktop screen sizes.
